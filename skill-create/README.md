# skill-create · 技能创建指南

指导创建符合规范的 Agent Skill：目录结构、SKILL.md frontmatter 约定（name/description）、描述写法（WHAT + WHEN + 第三人称 + 触发词）、核心原则（简洁、渐进披露、自由度分级）、常见反模式。本仓库中的 `spec-driven-coding` 与 `solution-design` 均按此指南创建并验证。

## 来源

改编自 [best-skills](https://github.com/xstongxue/best-skills)（Apache 2.0，原为 Cursor 技能指南），许可文本见仓库根 [licenses/APACHE-2.0.txt](../licenses/APACHE-2.0.txt)。

## 已知边界

- 面向 SKILL.md 约定的 Agent（Claude Code 等），不含特定平台（Cursor/Codex）的安装与集成细节
- 不覆盖技能的自动化测试（如 skill-doctor 类校验），仅覆盖编写规范
