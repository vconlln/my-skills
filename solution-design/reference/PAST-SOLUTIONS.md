# 过去的方案索引（待填充）

> 本文件是「过去的方案」的人工索引。技能运行时会**同时**自动扫描 `docs/**/方案设计.md` 与 `docs/**/需求理解.md`（dev-workflow 落盘的历史），两者合并作为历史方案来源。

## 维护规则

- **状态**受控三值：`在用` / `演进中` / `已废弃`
- 状态为 `已废弃` 时，备注列**必填**废弃原因与替代方案
- 路径优先写仓库内相对路径（如 `docs/order/方案设计.md`）；跨仓库方案写明仓库与位置
- 核心思路保持一句话——细节让读者去看方案原文，索引只做路由
